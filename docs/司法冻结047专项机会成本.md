## 长期情景测算（单位：万元）

口径（月化 8% 复利）：

```text
未来新增机会成本 = 本金 × [(1.08)^未来月数 − 1]
累计机会成本 = 截至日已产生机会成本 + 未来新增机会成本
预计本金损失 = 本金 × 预计无法追回率（风险情景，不是已确认坏账）
预计总经济损失 = 累计机会成本 + 预计本金损失
```

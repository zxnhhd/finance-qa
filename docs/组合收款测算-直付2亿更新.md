# 组合收款测算（按 6 月全部收支流水）

## 口径纠正

| 项目 | 错误口径 | **本版正确口径** |
|------|----------|------------------|
| 测算基数 | 只拿银行卡流水 5.72 亿 | **6 月全部收支流水 7.81 亿**（银行卡 + 支付宝/微信等） |
| 直付 2 亿 | 误当成从基数里切销售额/切全部 | **仅银行卡侧**匹配收付：日收 666.67 万、同日支 666.67 万 |
| 其他通道 | 被排除在分配外，仿佛不计费 | **留在剩余流水中**，按公户/第三方/个人卡分配后照常计税或手续费 |
| 分配对象 | 只分配银行卡剩余 | **分配「总流水 − 银行卡直付收支剥离」后的全部剩余** |

## 6 月流水结构

| 项目 | 金额（万元） | 说明 |
|------|-------------:|------|
| **全部收支流水（测算基数）** | **78,110.02** | 银行卡 + 支付宝/微信等 |
| 其中：银行卡 | 57,166.18 | 直付 2 亿针对这一侧 |
| 其中：其他通道 | 20,943.84 | 支付宝、微信等，不因直付而消失 |
| 银行卡直付剥离（收+支） | 40,000.00 | 月收 2 亿 + 月支 2 亿 |
| **经我方剩余（待分配）** | **38,110.02** | 含其他通道，全部要分配并计费 |

## 约束与前提

1. 主体下限：已有 **3** 家小规模主体 → A/B/C = **3 / 6 / 12**  
2. 私卡厚度（剩余扣公户后）：**70% / 25% / 3%**  
3. 费率：  
   - 公户小规模：寄售服务费 × **1.06%**（增值税 1% + 附加 6%）  
   - 第三方（含支付宝/微信等归入此通道的部分）：**0.32%**  
   - 个人卡隐性：**0.049546%**  
4. 直付通道：客户→采购方，**不计**我方第三方手续费与私卡隐性；**不表示**其他通道免费

## 计算过程（逐步）

### 第 1 步：测算基数 = 全部流水（不是只银行卡）

\[
\text{基数} = 781{,}100{,}173.80 \text{ 元} = 78{,}110.01738 \text{ 万元}
\]

分解：

\[
\text{银行卡} = 57{,}166.17691,\quad
\text{其他（支付宝/微信等）} = 20{,}943.84047
\]

### 第 2 步：银行卡直付匹配（有收也有支）

\[
\text{日均} \approx 666.67 \text{ 万（收）},\quad
\text{同日} \approx 666.67 \text{ 万（支给采购对手方）}
\]

\[
\text{月收} = 20{,}000 \text{ 万},\quad
\text{月支} = 20{,}000 \text{ 万}
\]

落地：客户直接打到采购方账户 → 该收、该支不进我方银行卡。

### 第 3 步：从总流水中只剥离这笔银行卡直付

\[
\text{剥离} = 20{,}000 + 20{,}000 = 40{,}000 \text{ 万元（占基数 }51.2098\%\text{）}
\]

\[
\text{经我方剩余} = 78{,}110.01738 - 40{,}000 = 38{,}110.01738 \text{ 万元}
\]

> 剩余里**包含**原支付宝/微信等约 2.09 亿，以及未直付的银行卡流水；这些都要进入公户/第三方/个人卡，**都要计费**。

### 第 4 步：公户与小规模税费

\[
\text{公户} = \text{主体数} \times 40 \text{ 万},\quad
\text{税费} = \text{公户} \times 1.06\%
\]

| 方案 | 主体 | 公户（万） | 税费（万） |
|------|-----:|-----------:|-----------:|
| A | 3 | 120 | 1.272 |
| B | 6 | 240 | 2.544 |
| C | 12 | 480 | 5.088 |

### 第 5–7 步：三方案分别计算

剩余扣公户后，私卡占比 A/B/C = 70% / 25% / 3%；第三方 = 其余。

\[
\text{第三方手续费} = \text{第三方} \times 0.32\%,\quad
\text{私卡隐性} = \text{个人卡} \times 0.049546\%
\]
\[
\text{综合成本} = \text{税费} + \text{第三方手续费} + \text{私卡隐性}
\]

#### 方案 A（3 家，私卡 70%）

1. 剩余₂ = 38,110.01738 − 120 = 37,990.01738  
2. 个人卡 = 37,990.01738 × 70% = 26,593.01217  
3. 第三方 = 37,990.01738 − 26,593.01217 = 11,397.00521  
4. 税费 = 1.272  
5. 第三方手续费 = 11,397.00521 × 0.32% = 36.47042  
6. 私卡隐性 = 26,593.01217 × 0.049546% = 13.17577  
7. **综合成本 = 1.27 + 36.47 + 13.18 = 50.92 万**

#### 方案 B（6 家，私卡 25%）

1. 剩余₂ = 38,110.01738 − 240 = 37,870.01738  
2. 个人卡 = 37,870.01738 × 25% = 9,467.50435  
3. 第三方 = 37,870.01738 − 9,467.50435 = 28,402.51304  
4. 税费 = 2.544  
5. 第三方手续费 = 28,402.51304 × 0.32% = 90.88804  
6. 私卡隐性 = 9,467.50435 × 0.049546% = 4.69077  
7. **综合成本 = 2.54 + 90.89 + 4.69 = 98.12 万**（贴近 100 万预算）

#### 方案 C（12 家，私卡 3%）

1. 剩余₂ = 38,110.01738 − 480 = 37,630.01738  
2. 个人卡 = 37,630.01738 × 3% = 1,128.90052  
3. 第三方 = 37,630.01738 − 1,128.90052 = 36,501.11686  
4. 税费 = 5.088  
5. 第三方手续费 = 36,501.11686 × 0.32% = 116.80357  
6. 私卡隐性 = 1,128.90052 × 0.049546% = 0.55933  
7. **综合成本 = 5.09 + 116.80 + 0.56 = 122.45 万**（超出 100 万预算）

## 为什么仍推荐 B

1. 基数已覆盖全部收付方式，支付宝/微信等不会“漏计费”  
2. 银行卡直付只降银行卡暴露，其他通道费用照计  
3. B 成本约 98 万，控冻与周转平衡，贴预算  
4. C 第三方过重，约 122 万超预算

# 组合收款测算（近两个月销售额）——三方案详细计算

## 一、先算清楚「饼有多大」

用 **2026 年 5 月、6 月** 销售额的平均值当基数（公司这段时间业务已抬到这个水平）：

- 5 月销售额：372,464,402 元  
- 6 月销售额：373,465,098 元  
- **月均销售额基数** = (372,464,402 + 373,465,098) ÷ 2 = **372,964,750 元** = **37,296.475 万元**

后面所有「占比」，都是相对这个 **37,296.475 万元**。

---

## 二、先拿走「直付采购」这一块（三种方案都一样）

业务要求：每月大约有 **2 亿元**货款，客户直接打到采购方账户（日均约 666.67 万进、同时约 666.67 万用于买表）。  
这笔钱 **不经过我们公司收款**，所以：

- 不算我们的第三方收款手续费  
- 不算我们的个人卡冻结隐性成本  

金额：

- 直付金额 = **20,000 万元**  
- 直付占比 = 20,000 ÷ 37,296.475 = **53.62%**

扣掉直付后，还要在我们这边走收款通道的钱：

- **还需分配的销售额** = 37,296.475 − 20,000 = **17,296.475 万元**  
- 这部分占比 = 17,296.475 ÷ 37,296.475 = **46.38%**

下面 A/B/C，都是把这 **17,296.475 万元** 再拆成：

1. **公户**（小规模主体寄售服务费）  
2. **第三方**（支付宝/微信等平台收款）  
3. **个人卡**

费率约定：

- 公户税费（小规模）= 公户金额 × **1.06%**（增值税 1% + 附加 6%）  
- 第三方手续费 = 第三方收款额 × **0.32%**  
- 个人卡隐性成本 = 个人卡收款额 × **0.049546%**  
- 每家主体每月寄售服务费按 **40 万元**  
- 综合成本 = 税费 + 第三方手续费 + 个人卡隐性成本  

---

## 三、方案 A：3 家主体，个人卡偏多（保周转）

### 1）公户怎么定

- 主体数 = **3 家**（公司已有 3 家在缴，不能再少）  
- 公户金额 = 3 × 40 = **120 万元**  
- 公户占比 = 120 ÷ 37,296.475 = **0.32%**  
- 税费 = 120 × 1.06% = **1.27 万元**

### 2）扣掉公户后，还剩多少可分给第三方和个人卡

- 扣公户后可分配额 = 17,296.475 − 120 = **17,176.475 万元**

方案 A 设定：这 17,176.475 万里，**70% 走个人卡，30% 走第三方**。

### 3）个人卡

- 个人卡金额 = 17,176.475 × 70% = **12,023.53 万元**  
- 个人卡占比 = 12,023.53 ÷ 37,296.475 = **32.24%**  
- 个人卡隐性成本 = 12,023.53 × 0.049546% = **5.96 万元**

### 4）第三方

- 第三方金额 = 17,176.475 − 12,023.53 = **5,152.94 万元**  
- （验算：17,176.475 × 30% = 5,152.94）  
- 第三方占比 = 5,152.94 ÷ 37,296.475 = **13.82%**  
- 第三方手续费 = 5,152.94 × 0.32% = **16.49 万元**

### 5）方案 A 汇总

| 项目 | 金额（万元） | 占销售额 |
|------|-------------:|---------:|
| 直付采购 | 20,000.00 | 53.62% |
| 公户 | 120.00 | 0.32% |
| 第三方 | 5,152.94 | 13.82% |
| 个人卡 | 12,023.53 | 32.24% |
| **合计** | **37,296.47** | **100%** |

| 费用项 | 金额（万元） |
|--------|-------------:|
| 税费 | 1.27 |
| 第三方手续费 | 16.49 |
| 个人卡隐性成本 | 5.96 |
| **综合成本** | **23.72** |

## 四、方案 B：6 家主体，均衡（推荐）

### 1）公户怎么定

- 主体数 = **6 家**  
- 公户金额 = 6 × 40 = **240 万元**  
- 公户占比 = 240 ÷ 37,296.475 = **0.64%**  
- 税费 = 240 × 1.06% = **2.54 万元**

### 2）扣掉公户后，还剩多少

- 扣公户后可分配额 = 17,296.475 − 240 = **17,056.475 万元**

方案 B 设定：这 17,056.475 万里，**25% 走个人卡，75% 走第三方**。

### 3）个人卡

- 个人卡金额 = 17,056.475 × 25% = **4,264.12 万元**  
- 个人卡占比 = 4,264.12 ÷ 37,296.475 = **11.43%**  
- 个人卡隐性成本 = 4,264.12 × 0.049546% = **2.11 万元**

### 4）第三方

- 第三方金额 = 17,056.475 − 4,264.12 = **12,792.36 万元**  
- （验算：17,056.475 × 75% = 12,792.36）  
- 第三方占比 = 12,792.36 ÷ 37,296.475 = **34.30%**  
- 第三方手续费 = 12,792.36 × 0.32% = **40.94 万元**

### 5）方案 B 汇总

| 项目 | 金额（万元） | 占销售额 |
|------|-------------:|---------:|
| 直付采购 | 20,000.00 | 53.62% |
| 公户 | 240.00 | 0.64% |
| 第三方 | 12,792.36 | 34.30% |
| 个人卡 | 4,264.12 | 11.43% |
| **合计** | **37,296.48** | **100%** |

| 费用项 | 金额（万元） |
|--------|-------------:|
| 税费 | 2.54 |
| 第三方手续费 | 40.94 |
| 个人卡隐性成本 | 2.11 |
| **综合成本** | **45.59** |

## 五、方案 C：12 家主体，个人卡很少（强控冻）

### 1）公户怎么定

- 主体数 = **12 家**  
- 公户金额 = 12 × 40 = **480 万元**  
- 公户占比 = 480 ÷ 37,296.475 = **1.29%**  
- 税费 = 480 × 1.06% = **5.09 万元**

### 2）扣掉公户后，还剩多少

- 扣公户后可分配额 = 17,296.475 − 480 = **16,816.475 万元**

方案 C 设定：这 16,816.475 万里，**3% 走个人卡，97% 走第三方**。

### 3）个人卡

- 个人卡金额 = 16,816.475 × 3% = **504.49 万元**  
- 个人卡占比 = 504.49 ÷ 37,296.475 = **1.35%**  
- 个人卡隐性成本 = 504.49 × 0.049546% = **0.25 万元**

### 4）第三方

- 第三方金额 = 16,816.475 − 504.49 = **16,311.98 万元**  
- （验算：16,816.475 × 97% = 16,311.98）  
- 第三方占比 = 16,311.98 ÷ 37,296.475 = **43.74%**  
- 第三方手续费 = 16,311.98 × 0.32% = **52.20 万元**

### 5）方案 C 汇总

| 项目 | 金额（万元） | 占销售额 |
|------|-------------:|---------:|
| 直付采购 | 20,000.00 | 53.62% |
| 公户 | 480.00 | 1.29% |
| 第三方 | 16,311.98 | 43.74% |
| 个人卡 | 504.49 | 1.35% |
| **合计** | **37,296.47** | **100%** |

| 费用项 | 金额（万元） |
|--------|-------------:|
| 税费 | 5.09 |
| 第三方手续费 | 52.20 |
| 个人卡隐性成本 | 0.25 |
| **综合成本** | **57.54** |

# 组合收款测算（更新：直付采购 2 亿 + A/B/C 拉开对比）

## 新前提

1. **直付采购通道（不过我方收付款）**  
   - 每月约 **2 亿元**客户表款，不进我方银行卡  
   - 由客户直接打至采购方提供的账户  
   - 日均约 **666.67 万元**  
   - 目的：压降我方银行卡收支流水，降低账户风控与冻结风险  
2. **销售基数**仍用上半年月均约 **29,761.62 万元**  
3. 经我方通道的剩余流水 ≈ **9,761.62 万元/月**（约 32.80%）  
4. A/B/C 只切分这剩余流水，并把**私卡厚度明显拉开**，便于对比  
5. **私卡隐性费率**已按 6 月流水最新口径：冻结风险 0.0352% + 司法坏账 0.0143% = **综合 0.0495%**

## 通道结构

| 通道 | 含义 | 成本口径 |
|------|------|----------|
| 直付采购 | 客户→采购方，不经我方卡 | 不计第三方手续费、不计我方私卡冻结隐性成本 |

| 个人卡 | 私卡收付 | 隐性费率约 0.049546%（冻结风险+司法坏账） |

## 为什么仍推荐 B

1. 直付 2 亿已经拿走大半流水，经卡暴露大降  
2. B 在销售额维度把私卡压到约 **8%**（剩余内约 25%），控冻与应急周转平衡  
3. A 私卡仍高，冻结风险明显更大  
4. C 私卡过薄，剩余几乎全靠第三方，弹性不足  

## 直付通道注意点（不计费但不等于零风险）

- 需固化：谁提供收款账户、如何核对到货/结算、异常追索  
- 避免“口头改卡号直打”  
- 与我方台账、采购单必须当日勾对

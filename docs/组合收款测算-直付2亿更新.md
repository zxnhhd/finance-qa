# 组合收款测算（按近两个月销售额均值）

## 销售额基数选哪个？

上半年各月销售额（元）：

| 月份 | 销售额 | 环比 |
|------|-------:|-----:|
| 2026-01 | 254,608,842 | +9.85% |
| 2026-02 | 216,509,084 | −14.96% |
| 2026-03 | 256,373,869.88 | +18.41% |
| 2026-04 | 312,276,006 | +21.80% |
| 2026-05 | 372,464,402 | +19.27% |
| 2026-06 | 373,465,098 | +0.27% |

对照：

| 基数口径 | 金额（万元） | 评价 |
|----------|-------------:|------|
| 1–6 月均 | 29,761.62 | **偏低**，被 1–4 月拉低，不能代表当前规模 |
| **5–6 月均（近两个月）** | **37,296.48** | **推荐**：反映当前平台期，又比单月稳 |
| 仅 6 月 | 37,346.51 | 与近两月几乎相同，可作对照 |

**结论：应用近两个月（5–6 月）销售额均值做通道占比与综合成本测算，不宜用上半年月均。**  
业务在增长时，月均会被早期低基数拉低，算出的绝对费用（手续费等）会系统性低估。

> 计费仍按**销售额（收款侧）**，不用收+支流水作税基。流水只说明银行卡风控暴露。

## 本版口径

1. **计费基数**：5–6 月均 **37,296.475 万元**  
2. **直付 2 亿**：从销售额切走收款侧 **20,000 万**（客户直付采购方）  
3. **经我方剩余**：17,296.475 万 → 公户 / 第三方 / 个人卡  
4. **主体**：3 / 6 / 12（不低于现有 3 家）  
5. **私卡厚度**（剩余扣公户后）：70% / 25% / 3%  
6. 费率：公户小规模 1.06%；第三方收款 0.32%；私卡隐性 0.049546%

---

## 方案 A（3 家，私卡 70%）→ 综合成本 23.72 万

1. 公户 = 3 × 40 = 120 万；税费 = 120 × 1.06% = **1.27 万**  
2. 剩余₂ = 17,296.475 − 120 = 17,176.475 万  
3. 个人卡 = 17,176.475 × 70% = **12,023.53 万**  
4. 第三方 = 17,176.475 − 12,023.53 = **5,152.94 万**  
5. 第三方手续费 = 5,152.94 × 0.32% = **16.49 万**  
6. 私卡隐性 = 12,023.53 × 0.049546% = **5.96 万**  
7. **合计 = 1.27 + 16.49 + 5.96 = 23.72 万**

## 方案 B（6 家，私卡 25%）→ 综合成本 45.59 万（推荐）

1. 公户 = 6 × 40 = 240 万；税费 = 240 × 1.06% = **2.54 万**  
2. 剩余₂ = 17,296.475 − 240 = 17,056.475 万  
3. 个人卡 = 17,056.475 × 25% = **4,264.12 万**  
4. 第三方 = 17,056.475 − 4,264.12 = **12,792.36 万**  
5. 第三方手续费 = 12,792.36 × 0.32% = **40.94 万**  
6. 私卡隐性 = 4,264.12 × 0.049546% = **2.11 万**  
7. **合计 = 2.54 + 40.94 + 2.11 = 45.59 万**

## 方案 C（12 家，私卡 3%）→ 综合成本 57.54 万

1. 公户 = 12 × 40 = 480 万；税费 = 480 × 1.06% = **5.09 万**  
2. 剩余₂ = 17,296.475 − 480 = 16,816.475 万  
3. 个人卡 = 16,816.475 × 3% = **504.49 万**  
4. 第三方 = 16,816.475 − 504.49 = **16,311.98 万**  
5. 第三方手续费 = 16,311.98 × 0.32% = **52.20 万**  
6. 私卡隐性 = 504.49 × 0.049546% = **0.25 万**  
7. **合计 = 5.09 + 52.20 + 0.25 = 57.54 万**

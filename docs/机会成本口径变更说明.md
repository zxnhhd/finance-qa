# 机会成本口径变更说明

## 变更时间

2026-07-22

## 旧口径

```
单笔机会成本 = 冻结金额 × 年化回报率(8%) × 冻结天数 ÷ 365
```

## 新口径（现行基准）

```
单笔机会成本 = 冻结金额 × [(1 + 月化回报率8%)^(冻结天数 ÷ 30) − 1]
```

附加业务假设：

- 当月收益继续投入，参与下月收益，即按月复利
- 1 个月本金倍数：`1.08`
- 9 个月本金倍数：`(1.08)^9 ≈ 1.999`，即接近翻倍
- 9 个月累计收益率：约 **99.90%**
- 12 个月有效年化收益率：`(1.08)^12−1 ≈ 151.82%`

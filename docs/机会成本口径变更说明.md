# 机会成本口径变更说明

## 变更时间

2026-07-22

## 旧口径

```
单笔机会成本 = 冻结金额 × 年化回报率(8%) × 冻结天数 ÷ 365
```

## 新口径（现行基准）

```
单笔机会成本 = 冻结金额 × 月化回报率(8%) × 冻结天数 ÷ 30
```

附加业务假设：

- 资金滚动使用，**9 个月翻一轮**
- 单轮理论回报 = 8% × 9 = **72%**
- 简单年化约 = 8% × 12 = **96%**

# FinanceQA · 资金支付体系问答

基于《资金支付体系优化方案报告》的内部问答知识库。  
**后续所有问答以该报告数据为唯一基准**；若报告数据变更，需同步更新基准文件。

## 数据基准

| 文件 | 作用 |
|------|------|
| `data/source/资金支付体系优化方案报告.pdf` | 原始报告 |
| `data/report-baseline.json` | 结构化基准数据（版本号、指标、方案） |
| `docs/报告基准摘要.md` | 可读摘要 |
| `docs/私户付款风险控制方案.md` | 无双 U 盾条件下的私户付款风控流程 |
| `docs/私户付款指令单模板.md` | 付款指令单（可直接套用） |
| `js/knowledge.js` | 面向检索的问答条目 |

当前基准版本：`2026-07-22`（统计周期 2026-05-20 ~ 2026-07-15；机会成本按月化 8%、9 个月翻一轮）。

## 功能

- 按报告内容提问匹配
- 分类浏览：账户现状 / 冻结与机会成本 / 司法冻结 / 第三方支付 / 对公收款 / 组合方案 / 付款风控
- 关键词搜索

## 快速开始

```bash
npm start
```

或直接打开 `index.html`。

## 报告数据变更时怎么更新

1. 替换 `data/source/` 下的 PDF
2. 更新 `data/report-baseline.json` 中的数值，并提升 `meta.baselineVersion`
3. 同步修改 `js/knowledge.js` 与 `docs/报告基准摘要.md` 中的表述
4. 告知助手「报告已更新」，后续问答将按新基准执行

# FinanceQA · 财务问答

本地可运行的财务问答知识库站点。用于检索常见个人理财、投资入门、税务常识、财务规划与企业财务问题。

## 功能

- 提问匹配：根据关键词从本地知识库检索最相近答案
- 分类浏览：个人理财 / 投资入门 / 税务常识 / 财务规划 / 企业财务
- 关键词搜索：支持问题、标签与正文检索
- 免责提示：内容仅供学习参考，不构成专业建议

## 快速开始

直接用浏览器打开 `index.html`，或在项目根目录执行：

```bash
npm start
```

然后访问终端提示的本地地址（通常是 `http://localhost:3000`）。

## 扩展知识库

编辑 `js/knowledge.js`，按现有格式追加条目：

```js
{
  id: "unique-id",
  category: "个人理财",
  tags: ["标签1", "标签2"],
  question: "你的问题？",
  answer: "对应解答……"
}
```

如需新增分类，同步更新 `FINANCE_CATEGORIES`。
